# Prop simulation deliverables

For each future prop simulation subtask, deliver:

- A concrete implementation artifact within the scope of `docs/prop_simulation.md`.
- A runnable demonstration, preferably through the existing local web app, that
  executes the implemented code and shows its actual outputs. Keep synthetic
  fixtures clearly labeled and separate from the user's saved runs.
- Independent expected values and visible expected-versus-actual checks,
  including relevant rejection/boundary cases. Never hardcode success or present
  a later unimplemented subtask as completed.
- Saved, inspectable evidence/downloads and exact instructions for the user to
  reproduce and validate the demonstration. State the expected observations.
- Appropriate automated checks alongside the demonstration; a test count alone
  does not satisfy the demonstration requirement.

Update `docs/prop_simulation_review.md` as each subtask becomes demonstrable.
Preserve earlier review artifacts and their resolved rule/configuration snapshots.
